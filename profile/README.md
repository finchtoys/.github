# Finch Agent

**Finch Agent is a lightweight, easy-to-use desktop AI agent for macOS, Windows,
and Linux.**

You work with it in natural language. It reads and processes local files you
authorize, remembers context across sessions, and extends through mini tools,
skills, and MCP integrations.

## What it does

- **Remembers context** — retains what matters about you, your projects, and
  your spaces, so a new session continues earlier work instead of starting over.
- **Works with local files** — reads, searches, creates, and edits files inside
  the directories you authorize.
- **Picks the right model** — Anthropic, OpenAI, Kimi, MiniMax and others, or a
  local model. Selection is per conversation and per task.
- **Extends through code** — mini tools are real code-driven extensions rather
  than prompt templates. Skills are Markdown-defined capabilities. MCP connects
  external services.
- **Runs on a schedule** — recurring desktop tasks such as briefings,
  monitoring, and report generation.
- **Keeps you in control** — file writes, shell commands, web access, and other
  external actions are gated by explicit permissions.

## Who it's for

People who want AI to help realize their ideas without first learning prompt
engineering, agent frameworks, or AI jargon — creators and knowledge workers,
independent developers shipping their own products, and small teams automating
routine work.
